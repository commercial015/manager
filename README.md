# Smart Kisti Manager v28 — Professional Edition

Windows 11 desktop installment and DPS management application.

## Highlights
- Modern Windows 11 inspired glass/professional dashboard
- Customer, Kisti, DPS, Payment, Due/Overdue and Schedule management
- Collection Center and customer ledger
- Cashbook, analytics and business reports
- Native PDF report saving
- Backup/Restore and local JSON data storage
- Dark/Light theme
- Real-time dashboard clock and collection target ring
- GitHub Actions Windows x64 NSIS build

## Build
```bash
npm install
npm run build -- --publish never
```

GitHub Actions is configured to build the Windows installer without publishing to GitHub.
